# AGAP test build 0.1: what to try on the Infinix

Test build 0.1 is the first build for the group's phone (the app itself shows version 0.3.0). Please try the
steps below on the **Infinix Hot 70**, and send the answers back **within 2 days** (by **11 November**).

## What is in this build, and what is not yet

- **In:** Live Captions in **English**; Sound Alerts **listening** (it shows the last sound it detected as text).
- **Not yet:** Filipino captions (next build), the big alert screen with vibration, Event History,
  Demonstration Mode, the Sound Categories and Vibration Patterns pages, and the watch app. These come in M2.

## 1. Install (once)

1. Copy `agap-phone-0.1-test.apk` (51.8 MB) to the phone (USB cable, Google Drive, or Messenger file). The phone
   needs about 200 MB free.
2. Tap the file. If Android asks, allow your file app to **install unknown apps**, then tap **Install**.
3. Open **AGAP**. Allow the microphone when asked.

## 2. Live Captions, English

1. Keep the phone on **Wi-Fi** the first time. Open **Captions**. If it offers to download the English pack,
   tap the button and wait until it finishes.
2. Turn on **airplane mode** (Wi-Fi off).
3. Tap **Start** and read 5 sentences from your trial script at normal speed, about 1 metre away. Tap **Stop**.
4. Take a **screenshot**. Did the words appear? Did the text stay after Stop?

## 3. Sound Alerts

Still in airplane mode. Open **Alerts** and tap **Start**. From another phone or speaker about 1 metre away,
play each sound below for about 5 seconds, wait 5 seconds, then the next one:

| Sound | What the app showed (name and %) |
|---|---|
| Fire alarm | |
| Smoke alarm | |
| Car horn | |
| Doorbell | |
| Knocking on a door | |
| Someone talking (no alert expected) | |
| Music (no alert expected) | |

The grey "Testing info" line shows the closest Annex A sound and its % even when no alert fires. Please note it
for any sound that gave no alert.

Then, only for the sounds that gave **no** alert: open **Settings** (top right), set **Alert threshold** to
**30%**, go back to **Alerts**, tap **Start**, and play those sounds once more. Write down what appears (or nothing),
then set the threshold back to **50%**. Knocking and doorbells scored low in my own tests, so this tells me
whether a lower setting helps on your phone.

## 4. One microphone at a time

1. While Sound Alerts is listening, open **Captions** and tap **Start**. Sound Alerts must stop.
2. Press the phone's **Home** button while listening. Listening must stop.

## 5. Send back (by 11 November)

- Phone model and Android version (Settings > About phone).
- The table above, filled in, plus the screenshots from steps 2 and 3.
- Anything that crashed, froze, looked wrong, or was hard to read.
